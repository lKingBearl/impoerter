Install the bookmarklet

1
Make sure your bookmarks bar is visible
In Chrome or Edge press Ctrl+Shift+B. In Firefox press Ctrl+B. A bar should appear just below your address bar.
2
Drag this button to your bookmarks bar
Click and hold the button below, drag it up to your bookmarks bar, and let go. It will appear as a bookmark called "PoE Build Grabber".
⚔️ PoE Build Grabber
↑ Drag this up to your bookmarks bar
3
Go to a character page on poe.ninja
Navigate to any character — the URL looks like:
poe.ninja/poe2/profile/AccountName/...
4
Click the bookmarklet once on the character page
A yellow banner will appear at the top of the page confirming it's active. The page will load the character data in the background — the bookmarklet intercepts it automatically and opens this tool with the result ready. You don't need to do anything else.

How does it work?

When you visit a character page, poe.ninja makes a hidden background request to fetch the character's data. The bookmarklet intercepts that request the moment it happens, grabs the URL, and passes it directly to this tool — so you never need to open DevTools or find the URL yourself.
